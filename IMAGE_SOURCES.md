## 🎨 HOW TO USE THESE IMAGES

### In React Components:
```jsx
<img 
  src="[IMAGE_URL]?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80"
  alt="Descriptive text"
  className="w-full h-full object-cover opacity-20"
/>
```

### URL Parameters Explained:
- `ixlib=rb-4.0.3` - Library version
- `auto=format` - Auto format optimization
- `fit=crop` - Crop to fit dimensions
- `w=1200` - Width in pixels (adjust as needed)
- `q=80` - Quality (80-90 recommended)

### Optimization Tips:
1. **Use appropriate sizes** for different devices
2. **Add loading="lazy"** for off-screen images
3. **Always include alt text** for accessibility
4. **Crop parameter** helps maintain aspect ratios
5. **Quality 80-85** balances file size and quality
